# neo — Desktop（电脑版）· Release 仓库

本仓库是 **neo 电脑版（Windows）的发布仓库**，只放 Release 安装包，不含源码。

## 这是什么

**neo（电脑版）** 是一个基于开源内核的 Windows 本地代理客户端。需要特别说明的是：

- **内核（核心）是成熟的开源项目**：本程序通过子进程方式调用 [xray-core](https://github.com/XTLS/Xray-core) 与 [sing-box](https://github.com/SagerNet/sing-box)（随安装包分发，均遵循各自的开源许可证）。**所有代理协议、传输、加密能力全部来自上述开源项目，neo 没有实现任何私有代理协议。**
- **neo 做的事是客户端壳与分流路由机制的更改与优化**，包括：
  - 面向游戏的分流策略：TUN 模式下按进程名直连保护（内置 PUBG / CS2 / L4D2 / 三角洲行动等，支持自定义），游戏流量不经代理转发
  - 规则 / 全局 / 直连三模式、绕过局域网 / 绕过大陆 / 广告拦截（本地 rule-set）
  - 真连测速、下载测速、流量统计曲线、自动故障转移、多订阅管理
  - 全中文界面、磨砂玻璃深色 UI、托盘、开机自启、应用自更新
- 客户端本体为独立实现（行为对标，未抄 any GPL 客户端代码），感谢 XTLS 与 SagerNet 社区的上游工作。

## 下载与安装

见右侧 [Releases](https://github.com/lubenwei-lian/neo-desktop-release/releases)：下载最新的 `neo-setup-*.exe`（约 80MB，含内核与规则集），双击安装，全中文向导。应用内「设置 → 软件更新 → 检查更新」可检查新版本。

- 系统要求：Windows 10 19041+ / Windows 11，x64
- TUN 模式需要管理员权限（应用会引导提权重启）
