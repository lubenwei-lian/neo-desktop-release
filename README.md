# neo — Windows

基于开源内核的 Windows 本地代理客户端。本仓库只发布安装包，不含源码。

**[下载最新版本](https://github.com/lubenwei-lian/neo-desktop-release/releases)**

---

## 这是什么

neo Windows 版是一个运行在 Windows 上的本地代理客户端。它通过子进程方式调用 xray-core 与 sing-box 两个开源内核，内核随安装包一并分发。所有代理协议、传输方式与加密能力都来自这两个开源项目，neo 没有实现任何私有代理协议。

neo 的改动是客户端壳与分流路由机制的实现和优化。客户端本体为独立实现，行为对标常见客户端，没有抄写任何 GPL 客户端代码。

两个内核各自遵循自己的开源许可证：xray-core 为 Mozilla Public License 2.0，sing-box 为 GNU GPL v3。sing-box 上游明确要求，未经许可不得使用其名称或暗示与其存在关联，因此 neo 与 XTLS、SagerNet 官方没有任何关联。

## neo 做了哪些改动

### 游戏分流与进程直连保护

TUN 模式下按进程名分流。内置 PUBG、CS2、L4D2、三角洲行动等常见游戏的进程名，这些游戏的流量直接走物理网卡，不经代理转发，以降低对局延迟。可以自行添加其他进程名。

### 分流模式

提供规则、全局、直连三种模式：

- **规则模式**：国内域名与 IP 走直连，其余流量走节点；命中广告拦截规则时直接丢弃。
- **全局模式**：所有流量走节点。
- **直连模式**：不使用代理，全部流量走本地网络。

绕过局域网与广告拦截基于本地 rule-set 文件实现，不依赖联网更新。

### 代理功能

- 真连测速与下载测速
- 流量统计曲线
- 自动故障转移：当前节点不可用时自动切换到可用节点
- 多订阅管理

### 客户端体验

全中文界面、磨砂玻璃深色主题、系统托盘、开机自启，以及应用内自动更新。

## 下载与安装

到 [Releases](https://github.com/lubenwei-lian/neo-desktop-release/releases) 页面下载最新的 `neo-setup-*.exe`，安装包约 80MB，已包含内核与规则集。双击运行，安装向导为全中文。

应用内的「设置 → 软件更新 → 检查更新」可以检查并获取新版本。

- **系统要求**：Windows 10 19041 及以上，或 Windows 11；64 位系统。
- **TUN 模式**：需要管理员权限，应用会引导提权重启。
